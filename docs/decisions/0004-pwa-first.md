# 0004: PWA first, native shells later

Date: 2026-10-26. Status: accepted.
Context: 9-day build, judges need a live product, phones need the camera.
Decision: React + Vite PWA with camera access first. Native iOS (glassy, Liquid Glass style) and Android shells come later and reuse core, coach and design tokens.
Consequences: one UI to build now; design tokens are kept platform-neutral.
